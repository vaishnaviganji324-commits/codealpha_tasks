# 🤖 Basic Chatbot

A simple rule-based chatbot created using Python.

## 📌 About the Project

This project is a basic chatbot that communicates with the user through the terminal.

The chatbot recognizes predefined messages and provides predefined responses.

## 🛠️ Technology Used

- Python

## ✨ Features

- Responds to greetings
- Answers simple questions
- Uses predefined responses
- Allows continuous conversation
- Exit option using "bye" or "goodbye"

## 🧠 Concepts Used

- Functions
- if-elif-else statements
- while loop
- User input
- String methods
- Basic input/output

## ▶️ How to Run

Open the terminal and run:

```bash
python chatbot.py
```

## 💬 Example

```text
You: hello
Bot: Hi! Nice to meet you!

You: how are you
Bot: I am fine, thanks!

You: what is your name
Bot: I am a simple Python chatbot.

You: bye
Bot: Goodbye! Have a nice day!
```
